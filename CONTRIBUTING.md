# Contributing Guidelines

Contributions are welcome!

## How to Contribute
1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Push the branch to your fork.
6. Open a pull request describing your changes.

## Bug Reports
Include steps to reproduce the issue, expected behavior, actual behavior, and relevant screenshots or logs.

## Feature Requests
Explain the problem, the proposed improvement, and its expected benefits.

## Code Standards
Keep changes focused, readable, documented, and consistent with the existing project style.

## Documentation
Update the documentation whenever your changes affect setup, usage, or behavior.

## Review Process
Maintainers may request changes before accepting a contribution.
