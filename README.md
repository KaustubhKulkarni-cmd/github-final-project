# Git and GitHub Assignment

## About This Project
This repository demonstrates practical Git and GitHub skills, including repository documentation, licensing, contribution guidelines, Bash scripting, repository forking, and branch management.

## Objectives
- Create and manage GitHub repository files.
- Understand open-source licensing and contribution guidelines.
- Write a Bash script to calculate simple interest.
- Practice Git commands, including fork, merge, and branch inspection.

## Technologies Used
- Git
- GitHub
- Bash
- Windows PowerShell / Git Bash

## Project Files
- `README.md` — Project overview and instructions.
- `LICENSE` — Apache License 2.0.
- `CODE_OF_CONDUCT.md` — Community standards.
- `CONTRIBUTING.md` — Contribution guidelines.
- `simple-interest.sh` — Simple interest calculator.

## How to Run
Run the Bash script in Git Bash or another Bash-compatible terminal:

```bash
bash simple-interest.sh
```
